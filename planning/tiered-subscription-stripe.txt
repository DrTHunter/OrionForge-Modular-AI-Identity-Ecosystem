*** OPEN PRODUCT QUESTION — READ BEFORE WRITING ANY CODE ***
web/stripe_billing.py's access model was deliberately changed on 2026-06-26
(see planning/access-gating.txt): there is currently NO feature paywall.
get_user_tier() is hardcoded to return 'pro' for every authenticated user;
get_user_unlocked_agents / user_has_tool_access / user_owns_item all
short-circuit to "everything unlocked." The whole platform is pay-per-use
credits (2x LLM cost), not tier-gated. The single-tier Stripe subscription
checkout (create_checkout_session, mode="subscription", STRIPE_PRO_PRICE_ID)
is leftover code from before that pivot — it still runs and would record a
"pro" subscription in stripe_state.json, but get_user_tier() no longer reads
subscription status at all, so buying it currently does *nothing* for the
buyer.

So before building 3 tiers into the app, Trent needs to decide what a paid
tier actually buys under the current pay-per-use model. Feature-gating
(agents/tools/voice/agi_loop behind a paywall) would REVERSE the 2026-06-26
decision — don't assume that's still the intent. Options discussed but not
decided:
  (a) Re-introduce feature gating per tier (Starter/Plus/Pro unlock
      progressively more tools/agents) — undoes access-gating.txt.
  (b) Keep everything unlocked for all users; tiers instead grant perks on
      top of pay-per-use, e.g. a monthly bundled credit allowance, a
      discount on the 2x credit markup, priority LLM routing, or higher
      rate limits.
  (c) Some hybrid (e.g. AGI Loop / API access reserved for Plus+, since
      those are the most LLM-call-intensive features and are the ones most
      worth protecting on cost grounds — this was my proposed split in
      conversation before Trent redirected to "just create in Stripe first").

One illustrative version of (a)/(c), NOT decided/approved, for reference only:
  Starter $9.49  — free-tier features + unlimited messages/memory, advanced
                   tools, internet tools, premium skins; agents capped 10,
                   knowledge files capped 25.
  Plus    $14.49 — Starter + image generation, voice TTS/STT, cost tracker;
                   agents/knowledge files uncapped.
  Pro     $24.49 — Plus + AGI Loop, priority routing, API access.
