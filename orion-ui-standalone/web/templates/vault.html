Memory System — Technical Specs

Search Engine

Uses FAISS IndexFlatIP — a brute-force exact-search cosine similarity index. Every vector is compared to every query, so accuracy is 100% with zero approximation. No training or clustering is needed.

Future: IndexIVFFlat

If the vault ever needs to scale beyond 50K, FAISS supports IndexIVFFlat — clustered partitioning with K-means. Trades ~2–5% recall for dramatically faster search at large scale. Swappable with minimal code changes.
