Platform-hosted models are charged at 2× the token cost in credits. For example, if a response costs $0.02 in tokens, you'll be charged 3 credits.

🎙 Voice Services (TTS & STT)

Voice tools (Text to Speech and Speech to Text) require API keys from providers like OpenAI, ElevenLabs, or Deepgram.

Using platform-hosted API keys: charged at 2× the API cost in credits per use.
Using your own API keys: completely free after the one-time tool unlock.
