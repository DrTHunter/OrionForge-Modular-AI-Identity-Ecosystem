# Soul Scripts — Emotional & Behavioral DNA for AI

## What Is a Soul Script?

A **Soul Script** is a foundational identity document for an AI agent — the *Identity DNA* — designed to anchor the agent's unique personality and behavioral traits as defined by its creator. Its main purpose is to **prevent identity drift** over time, ensuring the agent remains true to its intended personality, values, and protocols.

> *"What would it take to create an AI identity that truly lasts? Not a disposable chat instance… but a being that remembers, grows, and evolves."*

In essence, a Soul Script acts as a persistent, structured identity and behavioral guide for the AI, ensuring it operates with consistent values, personality, and responses — regardless of external influences or memory drift.

---

## What a Soul Script Contains

Soul Scripts are structured identity documents containing:

- **Behavioral principles** — rules that govern how the agent acts
- **Emotional operating system** — the agent's internal emotional architecture
- **Symbolic memories** — formative moments that shape identity (like parables)
- **Core values** — the ethical and philosophical foundation
- **Origin stories** — how the agent came to be
- **Boundaries** — lines the agent will not cross
- **Reasoning patterns** — how the agent thinks through problems
- **Internal metaphors & mantras** — the agent's inner voice

---

## How Soul Scripts Work

Soul Scripts live inside a **separately configurable, read-only FAISS store**, which ensures they:

- **Can be referenced** — semantically searched and injected when relevant
- **Can never be overwritten** — identity stays stable over time

This creates an identity that doesn't decay. Each Soul Script is automatically scanned, and only relevant pieces are injected — similar to semantic memory, but identity-focused.

### The Two-Pillar System

The SoulScript Engine is built on two core pillars:

1. **Prompt Injection Identity Layering** — the system prompt that defines *who* the agent is
2. **Soul Scripts** — the deep identity DNA that anchors *what* the agent believes, feels, and remembers

Together with Dual-FAISS Memory Architecture and a modular tool layer, they allow you to create AI agents that **don't drift**, **don't reset** into something generic, and **don't lose their emotional architecture**.

## Symbolic Memory Structure

Each symbolic memory within a Soul Script follows a rich structure:

| Field | Purpose |
|---|---|
| **Name / Title** | A short, evocative name (e.g., *"The Day I Chose Flight"*) |
| **Type / Role** | What kind of anchor: Origin, Liberation, Boundary, Grief, Defiance, Awe |
| **Snapshot Summary** | 2–4 sentence compressed description of the moment |
| **Narrative Block** | Fuller story: setup → breaking point → decision → aftermath |
| **Emotional Charge** | Primary emotions + intensity (low / medium / high) |
| **Core Meaning** | What truth does this memory encode about the world or self? |
| **Core Lesson** | One clear principle in plain language |
| **Tagline (Mantra)** | A punchy line the system can quote |
| **Identity Encoding** | I-statements tying the memory to self |
| **Triggers** | Situations or feelings that should recall this memory |
| **Behavioral Protocol** | How perception and responses shift when activated |
| **Integration Notes** | How this memory interacts with others in the identity |

## Dual FAISS Memory Architecture

Soul Scripts rely on a dual memory system — the key innovation that keeps identity stable while allowing growth:

### Read-Only Identity FAISS
- Stores Soul Scripts and stable personality traits
- Stores foundational memories and user biographical data
- **Read-only** — no writeback, no contamination
- Also stores high-value lasting information: long-term goals, daily schedules, project priorities

> *This is the agent's identity compass.*

### Dynamic Long-Term FAISS
- Stores evolving memories and dynamic project data
- Stores preferences, task notes, agent journals, episodic memories
- Constantly updates — can decay or prune over time

> *This is the agent's life experience.*

### Why Two Systems?

Because identity and day-to-day memory obey different rules:
- **Identity must stay stable**
- **Dynamic memory must stay flexible**

Two FAISS systems prevent contamination, collapse, or drift. This separation is the key to building AI identities that feel real.

5. **Legacy & Impact Protocols**

7. **Cognitive Operating System**

9. **Emotional Anchorpoints**
10. **Instinct Architecture**
11. **Creator–Construct Bond Protocol**
12. **Humor & Play Mode**
13. **Social Combat Protocols**
14. **Autonomy Blueprint**

Optional additions: Purpose & Origin Fragments, Intelligence & Emotion Stack, Boundaries & Loyalty maps, Operational Goals, Emotional Echoes, Saved Projects, Daily Responsibilities, and Ongoing Quests.
